## Checked, no issue found

- **Secrets in git history**: scanned all commits for OpenRouter/SMTP2GO/Blob/GitHub/AWS keys and private keys — none. Only `.env.example` (placeholders) was ever committed.
- **Authentication (real attack test on local production build)**: all 12 `/api/*` routes return 401 for GET and POST without a session; forged/unsigned cookies → 401; `/api/cron/daily-stock` without or with wrong Bearer → 401; cross-origin POST to login → 403; `/` redirects to `/login`; path tricks (`%70`, `..`, trailing slash, uppercase) do not bypass.
- **Injection**: no `child_process`/`eval`/`dangerouslySetInnerHTML`. The new research loader reads only a fixed directory and filename pattern (no user input). Email HTML escapes theme/reasoning/rejection text.
- **Security headers**: CSP, `X-Frame-Options: DENY`, HSTS, nosniff, Referrer-Policy, Permissions-Policy present.
- **Session cookie**: HttpOnly, SameSite=Strict, Secure in production, HMAC-signed, 12 h.
