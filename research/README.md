# Manual research files

คำสั่ง `npm run generate -- research` จะอ่านไฟล์ `manual-prompts-YYYY-MM-DD.md` ที่วันที่ในชื่อไฟล์ใหม่ที่สุดเสมอ
เพิ่มรีเสิร์ชรอบใหม่ = สร้างไฟล์ใหม่ตามรูปแบบด้านล่าง แล้ว commit ไม่ต้องแก้โค้ด ถ้าวันเดียวกันมีหลายรอบ ให้ต่อท้ายเลขรอบ เช่น `manual-prompts-2026-11-02-2.md` (ไฟล์ที่ไม่มีเลขนับเป็นรอบที่ 1)

## ขั้นตอนรีเสิร์ช

ทำก่อนเขียนไฟล์ prompt ทุกรอบ

1. รวบรวม long tail keywords ยาว 3–5 คำ แบบที่ผู้ซื้อน่าจะพิมพ์จริง จากข่าว ฤดูกาล หรือภาพที่เคยขายได้ อย่างน้อย 3 เท่าของจำนวนหัวข้อที่ต้องการ คำแนะนำใต้ช่องค้นหาของ Adobe ใช้เป็นคำตั้งต้นได้
2. ใช้เบราว์เซอร์ในแอป Claude เปิด `https://stock.adobe.com/search?k=<คำค้น>` ทีละคำ เว้นอย่างน้อย 4 วินาที ไม่เกิน 30 คำต่อรอบ อ่านจำนวนจากชื่อแท็บหรือข้อความเหนือภาพ (Adobe อาจแสดงเป็นภาษาไทย) ถ้าเจอ CAPTCHA ให้หยุดและบอกเจ้าของ
3. บันทึกทุกคำลง `keyword-competition.csv` รวมคำที่ไม่ผ่าน
4. เลือกเฉพาะคำที่มีผลลัพธ์ **20–500** แล้วเปลี่ยนคอลัมน์ `selected` เป็น `yes` และดูภาพผลค้นหาว่าตรงหัวข้อจริง
5. ดูภาพ 3–5 อันดับแรกของแต่ละคำที่เลือก แล้วจดสั้น ๆ ในไฟล์ prompt ว่าภาพส่วนใหญ่เป็นแบบไหน (มุมกล้อง แสง มีคนหรือไม่ ฉาก) และยังขาดอะไร ภาพอันดับต้นคือสิ่งที่ผู้ซื้อเห็นก่อน
6. เขียน 10 ข้อจากคำที่ผ่านเท่านั้น ให้แต่ละข้อเติมสิ่งที่ยังขาดหรือทำได้ดีกว่าภาพอันดับต้น **ห้ามถอด prompt หรือเลียนแบบภาพใดภาพหนึ่ง** เพราะ Adobe ปฏิเสธงานที่ทำจากงานของคนอื่น และอาจกระทบบัญชีผู้ขาย

จำนวนผลลัพธ์บอกแค่จำนวนคู่แข่ง ไม่ได้บอกยอดขาย จึงต้องเริ่มจากคำที่มีเหตุผลว่าผู้ซื้อใช้จริง

## รูปแบบที่ระบบอ่าน

ต้องมี **10 ข้อพอดี** เรียงเลข 1–10 แต่ละข้อเป็นบรรทัดเดียว แล้วตามด้วยบรรทัดย่อย (เว้น 3 ช่อง):

```
1. **ชื่อภาพภาษาอังกฤษ (ใช้เป็น SEO Title)** — Buyer: ผู้ซื้อและงานที่นำไปใช้. Prompt ภาษาอังกฤษทั้งหมดในบรรทัดเดียว
   - Top results: ภาพอันดับต้นเป็นแบบไหนและยังขาดอะไร (ระบบข้ามบรรทัดนี้ ใช้เป็นบันทึก)
   - Category: หมวดหมู่ (ต้องมี)
   - Keywords: คำ, คำ, คำ ... (ต้องมี อย่างน้อย 15 คำที่ไม่ซ้ำกัน ระบบเก็บสูงสุด 25)
   - Fallback: Prompt สำรองเมื่อภาพถูกปฏิเสธเพราะเห็นใบหน้า (ไม่บังคับ)
```

ข้อความอื่นในไฟล์ (หัวข้อ, ลิงก์, บันทึกการค้น) ระบบจะข้ามไป
ถ้ารูปแบบผิด (ไม่ครบ 10 ข้อ, ไม่มี Category, คีย์เวิร์ดไม่ถึง 15) ระบบจะไม่สร้างภาพและไม่เสียเครดิต

ตรวจไฟล์ด้วย `npm test`
